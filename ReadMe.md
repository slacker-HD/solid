# 简单说明

一些Solidworks二次开发例子。开发环境为Solidworks 2020 + VS2026。

文档可参见： [我的博客](http://www.hudi.site/)。

## SampleAddIn

+ 最简单的Solidworks C# add-in 开发配置

## SampleExe

+ 最简单的Solidworks C# 独立程序开发配置
+ 启动Solidworks并打开文件

## SampleRibbon

+ 创建Ribbon标签页
+ 创建工具栏按钮
+ 创建下拉菜单

## SampleStatusBar

+ 修改底部状态栏文本
+ 切换状态栏窗格显示

## SamplePropertyManagerPage

+ 创建属性管理器页（PropertyManager Page）
+ 页面包含标签、文本框、数值框、滑块、列表框、下拉框、复选框、单选按钮、按钮、位图、位图按钮、选择框、内嵌 WinForms 控件、ActiveX 等控件

## SampleTaskPane

+ 创建任务窗格（Task Pane）
+ 任务窗格显示/隐藏
+ 通过窗口句柄把 WinForms 用户控件嵌入任务窗格

## SampleVbaMacro

+ 对话框内输入 Solidworks VBA 宏代码并直接运行（写入临时宏文件后调用 RunMacro2 执行）
